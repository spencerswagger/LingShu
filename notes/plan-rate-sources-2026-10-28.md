## 2. 各家原文摘录（可直接抄进实现文档）

### 2.1 腾讯云 TokenHub（官方，最近更新 2026-10-16）
- 官方原文：`单次请求的积分消耗 =（未命中缓存输入 Token 数 × 输入的抵扣系数 + 输出 Token 数 × 输出的抵扣系数 + 缓存命中 Token 数 × 缓存命中的抵扣系数）/ 1,000,000`
- 刊例积分价（积分/百万 tokens，输入未命中 / 输出 / 缓存命中）：GLM-5.3 = 160 / 560 / 40；GLM-5.3-Flash = 16 / 56 / 4.6；Kimi K3 = 400 / 2000 / 40；Kimi K2.7-Code = 130 / 650 / 26（刊例还原）
- 限时活动（2026-10-01 00:30 – 2026-10-30 12:00）：Auto 6 折、Kimi K2.7-Code 8 折（104/432/20.8）、Kimi K3 7.5 折（300/1500/30）、GLM-5.3 5.5 折（88/308/22）、GLM-5.3-Flash 7 折（11.2/39.2/3.22）
- 关键交叉验证：刊例积分价 ÷ 20 = 官网人民币刊例价（GLM-5.3：160/20 = 8 元、560/20 = 28 元、40/20 = 2 元）→ **腾讯的积分就是「人民币 × 20」**，1 积分 = ¥0.05

### 2.2 智谱 GLM Coding Plan（官方 docs.bigmodel.cn）

## 3. 单位 → 人民币当量（0.2.0 换算的核心结论）

**各家「积分/Credits/AFP」不是同一把尺子，必须先各自锚定人民币，再统一换算成灵枢积分。**

| 渠道 | 1 单位 = ? 人民币 | 依据 | 置信度 |
|---|---|---|---|
| 腾讯云 Token Plan | ¥0.05（20 积分/元） | 套餐额度 ÷ 月费，4 档 + Hy 4 档全部一致；且与刊例积分价 ÷ 20 = 人民币价互相印证 | 高（官方双证） |
| 讯飞 Astron 积分 | ¥0.01（100 积分/元） | 3 档套餐额度 ÷ 月费一致；GLM-5.2 输出积分 2800 ↔ API ¥28 吻合 | 高 |
| 火山 AFP | ¥0.002（500 AFP/元） | Agent Plan 4 档一致（40/20,000 … 1000/500,000） | 中高（档位额度为二手引官方） |
| 阿里云 Credits | ¥0.00277 ~ ¥0.00339（档位越高越便宜） | 套餐额度 ÷ 月费；**仅套餐锚定，模型系数未公布** | 中（只能算套餐均价） |

> 给 spencer 的一句话：**能算的四家里，1 元买到的东西差 5 倍以上**（火山 500 AFP/元 vs 阿里 ~300 Credits/元 vs 腾讯 20 积分/元 vs 讯飞 100 积分/元）——所以「积分」绝不能跨渠道按数字直接比，只能按「每元换多少 token」比。

## 7. 对 0.2.0 的三条产品结论（口径层面，供拍板）

1. **换算不能跨渠道比数字**：1 元买到的额度差 5 倍（火山 500 AFP/元、讯飞 100 积分/元、腾讯 20 积分/元、阿里约 300 Credits/元）。换算表必须「渠道 → 每元 token 数」，不能「积分对积分」。
2. **只有 4 家有可用的官方锚点**（腾讯/讯飞/火山/阿里套餐均价），智谱是推算、Kimi 无解、OpenCode 是美元。0.2.0 上线时，Kimi 和阿里（系数）必须显式标「估算」或先不上线，别让用户看着假精度做决策。
3. **同一模型不同渠道价差 3 倍以上**（GLM-5.3 输入：腾讯 8 元 / 智谱套内约 3.3 元 / 火山约 0.9 元）——这正是 P1「成本页多渠道对比」该讲的事，但前提是先把本文件的锚点做进数据集，否则对比图会打架。
