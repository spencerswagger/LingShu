# 成本页「多渠道对比 + 会话渠道溯源」前端接入

- 日期：2026-10-29
- 分支：`feat/cost-multichannel-trace`（与后端第一棒同一分支，PR #65）
- 对齐后端设计：`docs/designs/2026-10-28-cost-multichannel-trace-design.md`
- 范围：只改前端展示与 API 类型；不改计费口径、不动统计页/状态页、无新依赖

## 1. 开关怎么用

后端键 `console.cost_multichannel_trace`，**默认 false**。

- 读：`GET /configs/system` → `Data.Console.MultichannelTrace`。成本页进页先读它：
  - `false` → 多线对比与渠道轨迹**整块不出现**，页面与改造前逐像素一致（不发新参数、不请求 `/trace`）；
  - 读取失败 → 同样按关闭处理（老后端没有 `Console` 块也不会崩）。
- 写：`PUT /configs/system` 的**可选** `Console` 块。前端把它放在「计费配置 → 成本页增强视图」里，
  与三组全量配置一起提交；**只有确实读到过配置（`consoleLoaded`）才回写**，避免一次读取失败把开关静默关掉。
- 运行中被人关掉（读到 true、请求时已经 false）→ 新入口回 403。前端对这两个请求声明
  `silentStatuses:[403]`（`http.ts` 新增的逐请求选项），所以**不弹全局红条**，改为行内
  「增强视图未开启 + 去计费配置打开」的引导，同时把新视图收回，旧的统计/曲线/会话照常可用。

## 2. 定价曲线：多选多线

- 单线入口（`内部模型` 单选）保持不变；打开「多渠道对比」开关后多出一个多选
  （`ChannelModelIDs=a,b,c`，`multiple-limit=10`），选中 ≥1 条即进入多线模式。
- **一个都没选 = 单线模式**，请求不带 `ChannelModelIDs`，与改造前完全一致。
- 多线模式一律读 `Data.Lines[]`，**不读顶层 `Cost`/`Sale`**（多线请求没带单线参数，顶层是「未指定」的不可用线）。
- 渲染：每条线一个颜色（10 色调色板，与后端 10 条上限对齐），成本实线 / 售价虚线；
  图例用可点选的 `el-check-tag` 做**逐线显隐**（留一组按钮，而不是把图例塞进 canvas，窄屏也能点）。
- 不可用线（`Available=false`）：图例置灰 + 「不可用」+ `Reason` tooltip，图下方再列一条
  「不可用：原因」标签；**不画成 0、不给假曲线**。超档线曲线上断点，并列出「从 N tokens 起计费会失败」。
- 横轴上限**只认响应里的 `MaxTokens`**（线多时后端按线数自动收敛），meta 行显式写「自动收敛，以此为准」。
- 采样参数改为「只回传用户手动改过的字段」：否则多线模式会把后端下调后的 `MaxTokens` 再喂回去，越切越小。

## 3. 会话渠道轨迹

在「会话成本曲线」卡片下方追加一块（开关打开时才出现），与会话选择共用同一个选中会话。

- 横轴一律 `TurnNo`（含失败轮），不用 `Turn`；失败轮 y 断开、另用**空心红圈**占位（不连成假曲线）。
- 连续段用 `markArea` 交替底色 + 段列表（渠道/模型、轮次区间、调用次数、成本/售价）。
  段 → 轮次区间按后端 `Segments[].Points` 顺序消费 `Points` 推导；点数对不上就不给区间（不猜）。
- **三类点视觉严格区分**：
  | 类别 | 图形 | 颜色 | 文案 |
  | --- | --- | --- | --- |
  | 普通轮次 | 折线 + 小圆点 | 蓝 / 橙 | — |
  | 真实切换点（`Kind=actual`） | 实心 pin + 竖虚线 + 「真实切换 #N」 | 红 | 「真实切换 #N · 第 X 轮：A → B」 |
  | 预测打平点（`Kind=predicted`） | 紫色菱形 + 「预测打平点」 | 紫 | 「预测，非实际切换」标签 + 说明「不是账单里发生过的事实」 |
- `PredictedBreakEven` 语义：
  - `Matched=false` → 只展示 `Reason`，**不补算一个数**；
  - `null` 且已真实切换 → 明写「已发生真实切换，不再给出预测打平点」，**不占位成 0**；
  - `Matched=true` → 落点位置按「会话里上下文首次达到该 token 数的那一轮」**定位**（不改后端给的打平值）；
    会话没到过那个长度就不落点，只说明「最大上下文 X tokens，尚未达到」。
- `Limit` / `Truncated` 与会话曲线同口径，单独一条「轨迹已截断」提示。

## 4. 顺带修的一处

`VChart` 之前只注册了 `Line/Bar/Pie`，没注册 `ScatterChart`，所以成本页原有的
「失败轮」「超档（计费失败）」散点其实被 ECharts 静默忽略、根本没画出来。这次要用散点做切换点标记，
顺手补上 `ScatterChart`（纯前端渲染修复，无行为副作用）。
