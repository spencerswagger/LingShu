# V3 旁路计费 · 任务书（2026-11-19）

> 方案基线：`previews/v3-bypass-billing.html`（已确认）。本文件只写「做什么、怎么验收、分几步」，实现细节走代码与设计注释。

## 0. 目标

请求不再经过灵枢：nginx 把 `/v1/*` 直转 magpie；灵枢只做用户/令牌/价格，每分钟拉账本计费。
令牌明文即 magpie callerKey（灵枢生成 secret，调 magpie 页面接口 `add-key` 注入，**无需人工逐个开通**）。

## 1. 硬口径（已确认）

1. 一分钟延迟停机可接受；余额 ≤0 → 下个窗口禁用令牌。
2. 令牌 增/删 必须同步 magpie（旧令牌一次性批量补建）。
3. 拓扑完全只读，只有两处可写价格：对外模型=售价（营收），对内模型=成本价（成本）。
4. 审计只看账单；调用日志/会话/请求内容页面下线。
5. 成本价缺失时回落账本 `cost`（USD→积分）。
6. 计费字段已核实（magpie v0.1.4458）：`req`（营收归属）、`provider`+`model`/`served`（成本归属）、`callerKeyName`、tokens/cache、`cost/priced`。
   历史老记录无 `req` → 营收记空、成本照落。

## 2. 切片与验收

### S1 令牌 ↔ callerKey 同步
- 新增 `magpie.PageAdmin`（已完成：EnsureCallerKey/DeleteCallerKey，含单测）。
- 令牌创建：生成 32-hex secret → `EnsureCallerKey("ls-token-<id>", secret)` → 令牌明文=secret，`magpie_keys` 记录 name/cipher/state。
- 令牌删除/停用：`DeleteCallerKey` + 本地 state=DISABLED；失败进重试队列（5/20/60s，3 次）。
- 批量补建：`POST /api/v1/admin/tokens/magpie-keys/backfill`，返回成功/失败清单。
- 验收：新建令牌后 magpie 侧存在同名 key；删除后消失；100 个旧令牌补建成功率 100%，失败可重试。

### S2 nginx 直转
- `frontend/nginx.conf`：`location /v1/ { proxy_pass http://magpie:3425; }`，SSE 关缓冲、长超时；响应头剥离 `X-Magpie-* / Server / X-Powered-By`（保留 `x-request-id`）。
- 验收：四协议（Chat/Responses/Messages/Gemini）各一发，响应逐字节一致；错误体原样；无 magpie 头。

### S3 账本计费器
- 每分钟 cursor 拉 `/v1/magpie/usage/requests`；幂等键=账本 `id`。
- 每行写 `billing_records`：`revenue = 售价(req 对外模型) × 用量`；`cost = 成本价(provider/model) × 用量`，缺成本价回落账本 cost。
- 扣钱包、算毛利；余额 ≤0 → 禁用令牌并同步删 magpie key。
- 验收：随机 24h 用量，账单条数=账本行数；营收/成本/毛利与手算一致（误差 0）；余额扣减逐笔对；余额转负当窗禁用。

### S4 schema / 下线
- 迁移 0027：`internal_models` 加 `cost_rates JSONB DEFAULT '{}'`；`billing_records` 加 `magpie_request_id TEXT UNIQUE`（幂等）。
- 下线：逐请求代理（admission/proxy/callerKey 注入）、预扣（credit_holds 与扫描器）、对账页面。
- 验收：进程无残留引用；迁移在 15.5 万行老库上 <1s；回滚只依赖备份。

### S5 页面
- 拓扑只读 + 两处价格编辑（对外售价/对内成本价）。
- 菜单只剩：统计 / 拓扑 / 账本(只读) / 账单 / 用户 / 令牌 / 公告 / 系统。
- 下线：调用日志、会话、请求/响应查看、对账页。
- 验收：非价格字段不可编辑；账单明细含 时间/令牌/用户/对外模型/对内模型/tokens/营收/成本/毛利。

### S6 回归
- 真机（InstaBox）：全流程 + 100 并发压测 + 对账；发版前整库备份。

## 3. 风险

- magpie 挂=全站不可用（不兜底），监控告警必须到位。
- 拉取器停摆 >5 分钟告警；恢复后按 cursor 补拉。
- 令牌明文=callerKey：泄露影响单令牌；库中只存 hash/密文，页面只展示一次。
